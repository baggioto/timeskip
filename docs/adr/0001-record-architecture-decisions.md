# 0001: Record architecture decisions

- Status: Accepted
- Date: 2026-11-17

## Context
This is a portfolio project. The reasoning behind decisions matters as much as the code, both for future me and for anyone reviewing the repo.

## Decision
Record every significant decision as a short ADR in `docs/adr/`, numbered in order.

## Consequences
- Decisions are explained where reviewers can find them.
- Small overhead per decision; keep ADRs short.
