# 0005: iOS 18 minimum and an XcodeGen project

- Status: Accepted
- Date: 2026-11-17

## Context
The app uses the Observation framework (`@Observable`, iOS 17+) and the iOS 18 `Tab` API for the tab bar. `.xcodeproj` files are large, hard to review and conflict easily in git.

## Decision
- Minimum deployment target: **iOS 18**.
- The Xcode project is generated by **XcodeGen** from `project.yml`. The generated `Timeskip.xcodeproj` is git-ignored.
- Build settings: Swift 6, complete strict concurrency, `MainActor` as the default actor isolation, approachable concurrency.

## Consequences
- Covers the vast majority of active iPhones while allowing modern SwiftUI APIs.
- Project changes are reviewed as small YAML diffs. Contributors (and CI) run `xcodegen` before opening or building.
- `MainActor` by default means background work must be opted into explicitly (`nonisolated`, `@concurrent`, actors), which keeps UI code simple and makes concurrency visible where it matters.
